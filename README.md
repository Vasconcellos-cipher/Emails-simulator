# 📧 Email Simulator

A simple email simulator built with Python using object-oriented programming concepts.

<img width="618" height="920" alt="image" src="https://github.com/user-attachments/assets/144ea5cb-18b2-49ac-8be4-94291620a1c0" /> <img width="474" height="105" alt="image" src="https://github.com/user-attachments/assets/38eae6c9-79d0-413a-937e-f7846d2b200c" />


This project allows users to:
- Send emails
- Read emails
- Delete emails
- Check inboxes
- View timestamps
- Interact through terminal inputs

---

# 🚀 Features

✅ Create users  
✅ Send emails between users  
✅ Inbox system  
✅ Read full emails  
✅ Delete emails  
✅ Read/Unread status  
✅ Timestamp support  
✅ Interactive terminal menu  

---

# 🛠️ Technologies

- Python 3
- Object-Oriented Programming (OOP)
- Datetime module
